# テンプレート改善タスク

コンペ作業中に発見したテンプレート改善項目を記録するファイルです。
`/ds-template-update` スキルで追記されます。

**このファイルには未完了（`[TODO]` / `[IN PROGRESS]`）の項目だけを置く。**
完了したら本文ごと [docs/TODO_ARCHIVE.md](docs/TODO_ARCHIVE.md) へ移す
（本体は `/ds-resume` が毎セッション読む「次にやること」の一覧であり、
完了済みが積み上がると読むべき数件が埋もれる）。

## フォーマット

```markdown
## [YYYY-MM-DD] <優先度> — <タイトル>
- **説明**: ...
- **影響ファイル**: ...
- **状態**: [TODO / IN PROGRESS / DONE]
```
